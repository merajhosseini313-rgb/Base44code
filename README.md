# زمان‌یار — Zamanyar

فروشگاه اینترنتی ساعت (فارسی، کاملاً راست‌به‌چپ) با ظاهر گرم و مینیمال.
A premium Persian (RTL) watch store built with Vite + React.

## اجرا / Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # ساخت نسخه نهایی در dist/
npm run preview  # پیش‌نمایش نسخه ساخته‌شده
```

`npm run dev` روی پورت **3000** و روی `0.0.0.0` گوش می‌دهد.

## ساختار پروژه

```
src/
├─ main.jsx               نقطه ورود + بارگذاری فونت وزیرمتن
├─ App.jsx                مسیرها (Router)، چیدمان کلی، بازگردانی اسکرول
├─ styles/
│  ├─ base.css            توکن‌های طراحی، ریست، تایپوگرافی، دکمه‌ها
│  └─ app.css             قواعد چیدمان کلی
├─ lib/format.js          اعداد فارسی و قالب‌بندی تومان
├─ data/catalog.js        محصولات، دسته‌بندی‌ها، نظرات، مقالات
├─ context/
│  ├─ CartContext.jsx     سبد خرید (localStorage) + هزینه ارسال
│  └─ SearchContext.jsx   باز/بسته بودن جست‌وجو
├─ components/            هر کامپوننت با فایل CSS خودش
└─ pages/
   ├─ Home.jsx            صفحه اصلی (هیرو، اعتماد، دسته‌بندی، پرفروش‌ها، جدیدها، چرا، نظرات، وبلاگ، خبرنامه)
   ├─ ProductDetail.jsx   صفحه محصول (مشخصات فنی، تعداد، محصولات مرتبط)
   ├─ CategoryPage.jsx    فهرست محصولات یک دسته
   ├─ Checkout.jsx        تکمیل سفارش + تأیید سفارش
   └─ NotFound.jsx
```

## مسیرها

| مسیر | توضیح |
| --- | --- |
| `/` | صفحه اصلی |
| `/product/:slug` | صفحه محصول |
| `/category/:slug` | `men`، `women`، `sport`، `classic`، `smart` |
| `/checkout` | تکمیل سفارش |

## هویت بصری

- پس‌زمینه کرم/شنی (`#F2E8DE`)، مرکب قهوه‌ای تیره (`#2D2621`)، لهجه خاک‌رُسی (`#A8664A`).
  بدون طلایی، مشکی یا سرمه‌ای.
- فونت فارسی: Vazirmatn (نصب‌شده به‌صورت محلی با `@fontsource-variable/vazirmatn`).
  متن‌های لاتین (نام برند، شماره سری) با استک `--font-latin` و وزن ۸۰۰.
- همه اعداد نمایشی (قیمت، تعداد، امتیاز) با ارقام فارسی از `src/lib/format.js` تولید می‌شوند.
- تصویر ساعت یک SVG پارامتریک است (`components/WatchArt.jsx`): شکل قاب، رنگ بدنه، صفحه، بند و
  نوع اندیس هر محصول از پالت گرم انتخاب می‌شود، بنابراین همه تصاویر با هم هم‌خانواده‌اند.

## نکته برای نسخه بعدی (انیمیشن سه‌بعدی هیرو)

ساختار هیرو از قبل برای اسکرول‌محور شدن آماده است و نیازی به بازچینش ندارد:

- `data-hero-part="copy"` — ظرف متن، قیمت و دکمه‌ها (تغییر متن با اسکرول)
- `data-hero-part="stage"` — ظرف صحنه
- `data-hero-part="watch"` — ظرف تصویر ساعت (چرخش سه‌بعدی با اسکرول)

## داده‌ها

این نسخه فقط سمت کلاینت است؛ محصولات از `src/data/catalog.js` خوانده می‌شوند، سبد خرید در
`localStorage` نگه داشته می‌شود و ثبت سفارش در صفحه پرداخت تنها یک تأیید نمایشی است (بدون درگاه واقعی).
